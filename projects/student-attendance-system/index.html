Student Attendance Management System

A multi-role desktop app where students check in by scanning a QR code on their phone.

Built during TEN internship

  • Python
  • Tkinter
  • SQLite
  • http.server
  • qrcode

Source code ↗ Windows release ↗

What it does

Separate portals for teachers, students and principals; manual or QR attendance; pie-chart analytics; warnings for anyone below 75%; and a message channel for leave and correction requests.

Architecture

Tkinter interface over SQLite, with SHA-256-hashed credentials. A small HTTP server runs on a background thread and serves the phone check-in page over the local network.

Hardest problem

Stopping proxy attendance. Each QR code carries a random session token that stops working the moment the teacher closes the attendance window.

Outcome

Packaged as a downloadable Windows release on GitHub.
