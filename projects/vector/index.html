VECTOR

An air-traffic-control simulator I built by voice dictation. You play it with spoken ATC commands: separation missions, gates and pilot read-backs.

  • Python
  • FastAPI
  • Three.js
  • Web Speech API

More on my GitHub ↗

How you play

Separation missions, gates and pilot read-backs, all driven by your voice.

Built with

Python and FastAPI on the server, a Three.js 3D airspace in the browser, and the Web Speech API to hear your commands.

How I built it

By voice dictation with Wispr Flow, speaking instead of typing, the same way I built VANTAGE: ZERO.

Where it went next

On the same FastAPI and Three.js base, VECTOR has grown into a 3D air-combat prototype: pick an F-35 or a Su-57 and one of three fictional theatres, then intercept hostile aircraft and complete objectives while the server runs the battle every 80 ms.
